# Compendio ORV · Termo.IA.Dinámica

**Aplicaciones interactivas para el curso de Termodinámica**
Oscar Robles Vásquez · Departamento de Ingeniería Química · CUCEI, Universidad de Guadalajara

**▶ Abrir el compendio:** https://orrobles.github.io/compendio-orv/

---

## Qué contiene
38 aplicaciones web organizadas en las ocho unidades del curso:

| Unidad | Tema |
|---|---|
| 01 | Conceptos y definiciones |
| 02 | Sustancias puras: tablas de vapor y del R-134a, diagramas de propiedades, ecuaciones de estado |
| 03 | Energía, calor y trabajo |
| 04 | Primera ley y volumen de control |
| 05 | Segunda ley y entropía |
| 06 | Análisis de exergía |
| 07 | Ciclos de potencia y refrigeración |
| 08 | Psicrometría |

Las aplicaciones se usan desde el navegador, en computadora o celular, y no requieren instalación ni registro.

## Cómo se elaboraron
Las aplicaciones fueron desarrolladas con asistencia de inteligencia artificial (Claude, de Anthropic) y **validadas y verificadas por el autor**. Las tablas de propiedades se compararon con las formulaciones de referencia vigentes (IAPWS-95 para el agua; Tillner-Roth y Baehr para el R-134a; ASHRAE para el aire húmedo). El detalle de la revisión está en [NOTAS-TECNICAS.md](NOTAS-TECNICAS.md).

## Uso sin conexión a internet
Descargue el repositorio completo (botón verde **Code → Download ZIP**), descomprímalo y abra `index.html`. Las bibliotecas de gráficas, ecuaciones y fuentes están incluidas en la carpeta `lib/`, por lo que todo funciona sin internet mientras se conserve la estructura de carpetas.
