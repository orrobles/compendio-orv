▾ Ocultar concepto
La desigualdad de Clausius, ∮δQ/T ≤ 0, conduce al balance de entropía: ΔS = ∫δQ/T + Sgen, con Sgen ≥ 0. La entropía generada mide la irreversibilidad del proceso: Sgen = 0 solo en el límite reversible y Sgen < 0 es imposible. Explore tres procesos típicamente irreversibles y observe que Sgen > 0 siempre, y que tiende a cero al acercar el proceso al límite reversible.

Para un sistema cerrado: S₂ − S₁ = ∫δQ/Tb + Sgen. Para un volumen de control en estado estacionario: 0 = Σ Q̇k/Tk + ṁ(s₁ − s₂) + Ṡgen, es decir Ṡgen = ṁ(s₂ − s₁) − Q̇/Tb. El signo de Ṡgen clasifica el proceso: positivo → irreversible (posible), cero → reversible (límite), negativo → imposible.

El proceso isentrópico (s = constante) es el modelo ideal de turbinas, compresores y toberas adiabáticos. La eficiencia isentrópica compara el desempeño real con ese límite: ηT = wreal/ws (turbina), ηC = ws/wreal (compresor), ηN = V₂²/V₂ₛ² (tobera). Ayuda · Balance de Entropía (Entropía Aplicada)

¿Qué es esta aplicación?

Balance y generación de entropía con cálculo de eficiencias isentrópicas (turbina, compresor, tobera).

Cómo se usa

  1. Configure los parámetros de operación con los deslizadores o campos de entrada.
  2. Ejecute o actualice el cálculo y observe los diagramas e indicadores de desempeño.
  3. Modifique un parámetro a la vez para realizar análisis de sensibilidad.
  4. Abra las secciones «DESPLEGAR / CONTRAER» para consultar conceptos y desarrollos paso a paso.
Sugerencia didáctica. Resuelva el enunciado y los ejercicios de esta aplicación disponibles en el índice del Compendio ORV, y verifique sus resultados con la propia herramienta.
